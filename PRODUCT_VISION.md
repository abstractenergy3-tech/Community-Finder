# Community Finder — product vision

## Core promise

"Find useful things near you without having to know where to look."

## Discovery modes

### I need help
Examples:
- food
- housing
- employment
- transportation
- legal assistance
- financial assistance

### I want to participate
Examples:
- classes
- recreation
- volunteering
- support groups
- family activities
- community meetings
- cultural events

### I want something happening soon
Examples:
- today
- this weekend
- next week

## Trust-first design

Every result should answer:
- What is it?
- Where is it?
- Who is it for?
- When is it available?
- How much does it cost?
- Where did this information come from?
- When was it last checked?

## Accessibility

The production app should support:
- screen readers
- large text
- high contrast
- keyboard navigation where applicable
- plain-language descriptions
- multilingual content where source data permits
- map-free list navigation
- low-bandwidth use

## Safety

Do not infer sensitive personal attributes about users from their searches. Search history should not be used to make sensitive classifications. Location should be minimized and retained only when necessary for an explicitly requested feature.
