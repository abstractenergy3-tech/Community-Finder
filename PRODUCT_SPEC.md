# Product Specification

## Mission
Help people discover relevant local resources, programs, and community activities without needing to know which organization provides them.

## MVP user story
"As a person looking for help or something to do locally, I can search my area, filter results, and quickly understand what each listing offers and how to contact it."

## MVP features
1. Location by permission or ZIP code.
2. Search.
3. Categories.
4. Distance filter.
5. Free/paid filter.
6. Date/time filter.
7. Listing detail page.
8. Directions/contact links.
9. Source and last-verified date.
10. Report outdated information.

## Later features
- Saved resources
- Personalized alerts
- Calendar integration
- Organization accounts
- Event registration links
- Multilingual UI
- Accessibility preferences
- Push notifications
- Community recommendations
- Duplicate detection
- Automatic freshness checks

## Trust model
Every listing should have:
- Source
- Last checked timestamp
- Verification status
- Organization identity where possible
- Clear distinction between "verified" and "community submitted"

## Privacy
Collect the minimum necessary location data. Prefer on-device location/radius calculations when possible. Do not retain precise location unless a feature explicitly requires it and the user consents.
